867. Transpose Matrix

1. Problem Statement

Prompt

Given a 2D integer array matrix, return the transpose of matrix.

The transpose of a matrix is the matrix flipped over its main diagonal, switching the matrix's row and column indices.

3. Main Idea / Intuition

Core Rule

The whole problem is based on one mapping:

matrix[row][col] -> result[col][row]

Think About It

In a transpose, every value keeps its identity, but its position changes. The row index becomes the column index, and the column index becomes the row index.

So if a value is at [0][2] in the original matrix, it must go to [2][0] in the transposed matrix.

Original Position

matrix[1][2] = 6

This means: row 1, column 2.

New Position

result[2][1] = 6

The indices are swapped.

4. Step-by-step Walkthrough

Step 1

Get the size of the original matrix.

  • rows = matrix.length
  • cols = matrix[0].length
Step 2

Create a new matrix with reversed dimensions.

If the original matrix is rows x cols, then the transpose must be cols x rows.

Step 3

Visit every element in the original matrix using nested loops.

Step 4

Place each value into the swapped coordinate:

result[col][row] = matrix[row][col]

Detailed Walkthrough

Using matrix = [[1,2,3],[4,5,6]]:

Current Position Value Moved To Why
[0][0] 1 [0][0] Swap row and column: (0,0) stays (0,0)
[0][1] 2 [1][0] Row 0, col 1 becomes row 1, col 0
[0][2] 3 [2][0] Again, swap indices
[1][0] 4 [0][1] Row 1, col 0 becomes row 0, col 1
[1][1] 5 [1][1] Same value, mirrored on diagonal
[1][2] 6 [2][1] Indices swapped

5. Final JavaScript Solution

/**
 * @param {number[][]} matrix
 * @return {number[][]}
 */
var transpose = function(matrix) {
    const rows = matrix.length;
    const cols = matrix[0].length;

    // The transposed matrix has reversed dimensions:
    // original: rows x cols
    // result:   cols x rows
    const result = Array.from({ length: cols }, () => Array(rows));

    for (let row = 0; row < rows; row++) {
        for (let col = 0; col < cols; col++) {
            result[col][row] = matrix[row][col];
        }
    }

    return result;
};

6. Line-by-line Explanation

Line 1

const rows = matrix.length;

This gets how many rows the original matrix has.

Line 2

const cols = matrix[0].length;

This gets how many columns each row has.

Line 3

const result = Array.from({ length: cols }, () => Array(rows));

This creates the output matrix with reversed dimensions. We use Array.from so each row in result is a different array.

Nested Loops

We go through every cell in the original matrix. Since every value must appear in the answer, we cannot skip any cell.

Key Assignment

result[col][row] = matrix[row][col];

This is the transpose rule. It swaps the coordinates. That is the exact definition of matrix transposition.

Return

return result;

We return the newly built transposed matrix.

7. Common Mistakes

Mistake 1

Using the same dimensions for the result.

const result = Array.from({ length: rows }, () => Array(cols));

This is wrong because the transpose of a rows x cols matrix must be cols x rows.

Mistake 2

Copying instead of transposing.

result[row][col] = matrix[row][col];

This just recreates the original matrix. It does not swap row and column positions.

Mistake 3

Creating the 2D array incorrectly with fill.

const result = new Array(cols).fill(new Array(rows));

This makes every row reference the exact same array object. Updating one row updates all rows.

Why the fill bug happens 
const result = new Array(3).fill(new Array(2));

result[0][0] = 99;

console.log(result);
// [
//   [99, undefined],
//   [99, undefined],
//   [99, undefined]
// ]

The issue is not syntax. The issue is references. All three rows point to the same inner array.

Correct Version 
const result = Array.from({ length: cols }, () => Array(rows));

Now each row is created separately.

8. Complexity

Time Complexity

O(m * n)

We visit every element exactly once, where m is the number of rows and n is the number of columns.

Space Complexity

O(m * n)

We create a new matrix to store all values. The output holds the same total number of elements as the input.

9. Interview Explanation Version

30-Second Answer

First, I get the number of rows and columns from the input matrix. Since transposition swaps row and column indices, the result matrix must have reversed dimensions: cols x rows. Then I iterate through every cell and place each value at result[col][row]. That gives me the transposed matrix in O(m * n) time with O(m * n) extra space.

10. Pattern to Remember

Mental Model

Transpose means: swap row and column.

(r, c) -> (c, r)

If you remember that one rule, you can rebuild the whole solution during an interview.

11. Optional Brute Force Comparison

Is there a simpler brute force?

The direct nested-loop solution is already the practical brute force and also the correct optimal approach here. Since every value must move to a new coordinate, you must inspect every cell.

There is no meaningful faster-than-O(m * n) solution because the matrix contains m * n values and all of them matter.

Compact JavaScript Variant 
var transpose = function(matrix) {
    return matrix[0].map((_, col) => matrix.map(row => row[col]));
};

This is elegant, but for interviews the nested-loop version is usually better because it makes the logic more explicit.

12. Final Takeaway

Remember
  • The output dimensions are reversed.
  • The key mapping is matrix[row][col] -> result[col][row].
  • Use a fresh 2D array, not fill(new Array(...)).
  • This is a matrix traversal problem, not a hash map or two pointers problem.

Study focus: understand the coordinate swap, not just the final code.
