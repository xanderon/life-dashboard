LeetCode 1 — Two Sum

Array Hash Map Easy Interview Classic

Problem Statement

Given an array of integers nums and an integer target, return the indices of the two numbers such that they add up to target.

You may assume that each input has exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

Main Idea

For each number, compute the complement: 

const difference = target - nums[i];

If that complement already exists in the map, we found the answer.

Final JavaScript Solution

/**
 * @param {number[]} nums
 * @param {number} target
 * @return {number[]}
 */
var twoSum = function(nums, target) {
    // Store previously seen numbers and their indices
    const map = new Map();

    // Iterate once through the array
    for (let i = 0; i < nums.length; i++) {
        const current = nums[i];
        const difference = target - current;

        // If we have already seen the needed partner, return both indices
        if (map.has(difference)) {
            return [map.get(difference), i];
        }

        // Otherwise store current number and index
        map.set(current, i);
    }
};

Why This Works

Instead of comparing every pair, we remember what we have already seen. That lets us check the needed partner in constant average time.

Common Mistakes

  • Saving difference in the map instead of the current number.
  • Calling map.set(...) before checking map.has(...).
  • Forgetting that the map stores number → index.

Complexity

Time Complexity: O(n)

Space Complexity: O(n)
