Merge Sort — Simplified JavaScript Version

This version uses slice() and concat() to keep the code shorter and easier to explain in an interview. It is great for understanding the algorithm clearly: split recursively, then merge with two pointers.

Algorithms Sorting Divide and Conquer Recursion JavaScript Interview Prep

1. Title

Problem: Explain and implement Merge Sort in a simple, interview-friendly way.

Goal: sort an array like [5, 3, 8, 4, 2] into [2, 3, 4, 5, 8].

2. Problem Statement

Given an array of numbers, return a new array with the elements sorted in ascending order using Merge Sort.

Merge Sort is based on one main idea: break the array into smaller parts, sort those parts, then merge them back together.

3. Examples

Example 1

Input: [5, 3, 8, 4, 2]

Output: [2, 3, 4, 5, 8]

Example 2

Input: [4, 1, 3, 2]

Output: [1, 2, 3, 4]

4. Main Idea / Intuition

Merge Sort has 2 separate jobs:

  1. Split the array into smaller and smaller halves.
  2. Merge sorted halves back into one sorted result.

A single element is already sorted. So the recursion keeps dividing until every piece is tiny, and then the merge step rebuilds the answer in order.

6. Step-by-Step Walkthrough

Step 1: Start with [5, 3, 8, 4, 2]
Step 2: Split into two halves
[5, 3] and [8, 4, 2]
Step 3: Keep splitting recursively
[5, 3] → [5] and [3]
[8, 4, 2] → [8] and [4, 2]
[4, 2] → [4] and [2]
Step 4: Merge tiny sorted arrays
[5] + [3] → [3, 5]
[4] + [2] → [2, 4]
Step 5: Merge bigger sorted arrays
[8] + [2, 4] → [2, 4, 8]
Step 6: Final merge
[3, 5] + [2, 4, 8] → [2, 3, 4, 5, 8]

7. Final JavaScript Solution

function mergeSort(arr) {
  // Base case: arrays with 0 or 1 element are already sorted
  if (arr.length <= 1) return arr;

  const mid = Math.floor(arr.length / 2);
  
  const left = mergeSort(arr.slice(0, mid));
  const right = mergeSort(arr.slice(mid));

  return merge(left, right);
}

function merge(left, right) {
  const result = [];
  let i = 0;
  let j = 0;

  // Compare the current elements from both arrays
  while (i < left.length && j < right.length) {
    if (left[i] < right[j]) {
      result.push(left[i++]);
    } else {
      result.push(right[j++]);
    }
  }

  // Add whatever is left
  return result.concat(left.slice(i), right.slice(j));
}

// Example
console.log(mergeSort([5, 3, 8, 4, 2])); // [2, 3, 4, 5, 8]

8. Line-by-line Explanation

mergeSort(arr)

  • if (arr.length <= 1) return arr; → stop recursion when the array is already trivially sorted.
  • mid → find where to split the array.
  • arr.slice(0, mid) → take the left half.
  • arr.slice(mid) → take the right half.
  • Call mergeSort on both halves recursively.
  • Pass both sorted halves into merge().

merge(left, right)

  • result → the merged sorted array we build.
  • i and j → pointers into left and right.
  • The while loop continues as long as both arrays still have elements.
  • At each step, compare left[i] and right[j].
  • Push the smaller one, then move that pointer forward.
  • At the end, use concat(left.slice(i), right.slice(j)) to append the remaining items.

9. Why This Version Is Simpler

Cleaner recursion

Instead of creating leftHalf, rightHalf, sortedLeft, and sortedRight as separate variables, this version directly returns:

merge(mergeSort(...), mergeSort(...))

Cleaner leftovers

Instead of two extra while loops at the end, we simply append the remaining pieces with:

result.concat(left.slice(i), right.slice(j))

11. Common Mistakes

  • Forgetting the base case → recursion never stops.
  • Thinking the while loop does the splitting → it does not; it only merges.
  • Forgetting leftovers → one side may still have elements after the main loop ends.
  • Using shift() repeatedly → in JavaScript that is often less efficient because it reindexes the array.
  • Thinking merge sort is in-place → the classic array version uses extra memory.

12. Complexity

Metric Value Intuition
Time Complexity O(n log n) There are about log n levels, and each level does about n total merge work.
Space Complexity O(n) The algorithm creates new arrays while splitting and merging.

13. Interview Explanation Version

“Merge Sort is a divide-and-conquer algorithm. It recursively splits the array into halves until each piece has one element, then merges the sorted pieces back together. The merge step uses two pointers and runs linearly. Overall time is O(n log n), and the standard array implementation uses O(n) extra space.”

14. Pattern to Remember

Pattern: split → solve smaller problems → merge results

This same pattern shows up in many interview topics:

  • Recursion on binary trees
  • Divide and conquer problems
  • Merging sorted lists or arrays
  • Problems like counting inversions

16. Final Takeaway

Merge Sort = recursion for splitting + two pointers for merging.

In this simplified JavaScript version, slice() makes the split easier to read, and concat(left.slice(i), right.slice(j)) makes the ending of the merge cleaner.

This is a very good version for interview prep because the logic is easy to explain out loud.
